# Portfólio – Felipe Borges de Lima

Portfólio pessoal de Desenvolvedor Júnior.

## Abrir no computador
Abra a pasta no VS Code e clique com o botão direito em `index.html` → **Open with Live Server**
(extensão "Live Server"), ou simplesmente dê dois cliques no `index.html`.

## Estrutura
- `index.html` – página do portfólio
- `assets/css/style.css` – estilos da página
- `assets/js/main.js` – tema claro/escuro e animações
- `assets/foto.jpg` – foto de perfil
- `assets/capa.png` – imagem que aparece quando o link é compartilhado (LinkedIn, WhatsApp)

## Publicar no GitHub Pages
1. Crie um repositório público chamado `felipe-deev.github.io`.
2. Envie o conteúdo desta pasta (o `index.html` precisa ficar na raiz).
3. Em Settings → Pages, escolha a branch `main` e a pasta `/ (root)`.
4. O site fica em https://felipe-deev.github.io
